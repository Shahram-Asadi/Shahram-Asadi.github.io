03 // Approach

How I build AI that gets adopted.

Four rules I apply to every AI solution, from the first prototype to production.

01

Build vs buy

Start from the business need and compare options honestly. When building wins, use open-source components and AI-assisted development to ship fast.

02

Human in the loop

A person reviews and accepts every AI-extracted value before it is used, so AI output never enters business calculations unchecked.

03

Secure by design

AI runs behind secured cloud APIs, keys stay server-side, secrets follow least privilege, and everything sits on a Zero Trust foundation.

04

Governed adoption

Microsoft Copilot best practices, Copilot Studio agent governance standards, and support for executive decisions on AI platform security.

AI_GOVERNANCE // IDENTITY● IN PRACTICE

Governing AI agents as identities

An AI agent gets the same treatment as a person on the network: its own identity, only the access it needs, for only as long as it needs it, with a human approval and an audit trail. I apply this with Microsoft Entra ID and Copilot Studio.

  • LEAST PRIVILEGEAgents reach only the data and actions their task needs.
  • TIME-BOUND ACCESSAccess is granted after a security review and expires.
  • APPROVAL & AUDITPeople approve what agents do, and every action is logged.
“AI that people can trust is the only AI that gets adopted.”
